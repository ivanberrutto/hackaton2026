# Instrucciones del proyecto

## Contexto
Quiero crear una pagina front de ejemplo que muestre distintos proyectos agronomicos, partiendo de ejemplo otra pagina con objetivo crowdfunding parecido, que mantenga su diseño pero con otros colores mas enfocados a la agronomia.

## Estilo visual
- Color principal: verde claro agradable (tipo #90EE90 o similar)
- Mantener la estructura de proyectos y layout del original
- Cambiar todos los textos, nombres y marca por ejemplos enfocados a agronomia
